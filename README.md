# 📊 SuperStore Sales Analytics & Forecasting Dashboard

# Power BI | Excel | Power Query | DAX | Data Analytics | Business Intelligence

An interactive Business Intelligence dashboard built to transform raw sales data
into meaningful business insights and short-term sales forecasts.





# 🚀 Project Overview

The **SuperStore Sales Analytics & Forecasting Dashboard** is an end-to-end
data analytics project developed using **Power BI, Excel, Power Query, and DAX**.

The project focuses on transforming raw sales data into a clean, structured,
and interactive analytical dashboard that helps understand:

- 📈 Sales performance
- 💰 Profitability
- 📦 Product and category performance
- 👥 Customer segments
- 🚚 Shipping performance
- 💳 Payment modes
- 🌎 Regional/state performance
- 📅 Monthly sales trends
- 🔮 Short-term sales forecasting

The project also demonstrates practical **data cleaning, data quality checking,
data transformation, KPI development, business reporting, and data visualization**.

---

# 🎯 Business Objective

The objective of this project is to answer important business questions such as:

> **How are sales and profits performing?**

> **Which product categories and sub-categories contribute most to sales?**

> **Which customer segments generate the most revenue?**

> **Which regions and states have stronger sales performance?**

> **Which shipping and payment modes are most commonly used?**

> **What could the sales trend look like over the next 15 days?**

The dashboard converts these questions into interactive visual analysis.

# 🧹 Data Cleaning & Preparation

Before creating the dashboard, the raw dataset was analyzed and prepared
using **Power Query**.

# Data quality activities performed:

🔍 Checked columns for **null/missing values**
🧹 Handled appropriate missing numeric values
🗑️ Removed unnecessary columns
🔁 Detected duplicate records
✅ Validated the cleaned dataset
🔄 Transformed data into an analysis-ready format

This step ensured that the dashboard was built on cleaner and more reliable data.
